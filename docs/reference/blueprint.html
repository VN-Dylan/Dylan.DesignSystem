01

Mục tiêu & định nghĩa "hoàn thành"

Sản phẩm cuối là một bộ design system hoàn chỉnh, tự chứa, không phụ thuộc thư viện UI bên ngoài — tái hiện đầy đủ kho component của site mẫu eyris-react.themenate.net và có tài liệu hướng dẫn dùng.

Bàn giao

  • @dylan/tokens — design token (màu, type, spacing, radius, shadow, z-index, motion) ở dạng SCSS + CSS variables + Tailwind preset.
  • @dylan/ui — 42 base component + 42 composite component, mỗi cái có type, test, story.
  • @dylan/utils — 16 hook + 15 hàm + 1 HOC.
  • apps/showcase — dựng lại các trang app mẫu + 13 layout auth + landing.
  • Handbook: Storybook (playground + autodocs mỗi component) đã deploy.
  • DESIGN.md + docs/: nguyên tắc, bảng token, guideline dùng, accessibility, đóng góp.

Tiêu chí nghiệm thu

  • Mỗi component: khớp API (prop / type / default) với tài liệu Eyris, có story cho mọi biến thể chính, pass test, pass axe a11y.
  • Light + dark + RTL hoạt động qua token, không màu hard-code.
  • 8 preset theme schema đổi được lúc chạy.
  • Tree-shakeable, mỗi component import lẻ được; bundle base < ngưỡng đặt ra.
  • pnpm build, pnpm test, pnpm storybook:build, lint, typecheck đều xanh trong CI.
  • Mọi trang mẫu render đúng, không lỗi console.

Nguyên tắc kỹ thuật

  • Ranh giới package: ui phụ thuộc tokens + utils + icons; utils không phụ thuộc ui.
  • Styling: Tailwind cho bố cục & utility trong JSX; SCSS module (Component.scss) cho state phức tạp, animation, selector đặc thù — dùng @apply + @use "@dylan/tokens". Class có ngữ nghĩa dạng .dyl-btn.
  • Prop convention theo Eyris: variant, size (xs|sm|md|lg), shape, disabled, loading, block, icon, className nhận cả string lẫn (state) => string.
  • Compound component qua context: Avatar.Group, Tabs.TabList/TabNav/TabContent, Menu.MenuItem, Steps.Item, Carousel.Item…
  • Forwarding ref + spread props gốc cho mọi primitive.
04

Design token & theming

Chuyển hệ biến CSS của Eyris thành nguồn SCSS, rồi generate ra 3 đầu ra: CSS custom properties (runtime theming), Tailwind preset (utility), JSON (tài liệu + test).

Token nền (từ Eyris)

--primary #286cf0
--primary-deep #1f56c0
--primary-mild #4c86f4
--primary-subtle #286cf01a
--success #00a85b
--warning #f59e0b
--error #eb4137
--info #3380fa
gray-50 #fafafa → gray-950 #0a0a0a (11 bậc)

Cơ chế theme

  • Dark mode = class .dark trên <html> (Tailwind darkMode: 'class').
  • 8 preset schema (default, dark, green, purple, orange, cyan, gold, pink) — mỗi cái override primary / primaryDeep / primaryMild / primarySubtle / muted cho light+dark.
  • useThemeSchema() ghi biến vào documentElement.style; lưu localStorage; store Zustand (mode, schema, layout, direction).
  • RTL qua dir attribute + logical properties trong SCSS.

Token bổ sung cần chuẩn hoá

Spacing scale, radius (none / sm / DEFAULT / lg / xl / full — Eyris card ~12px), shadow, typography scale (heading/body/label + weight), z-index layer (dropdown, sticky, drawer, dialog, popover, toast), motion (duration + easing), breakpoint. Ghi hết vào DESIGN.md kèm bảng.

07

Quy trình dùng codex

Claude giữ vai trò kiến trúc & review; codex là "thợ nhân bản" theo khuôn đã chuẩn.

  1. Chuẩn khuôn (một lần): Claude hoàn thiện 5 component vàng + RECIPE.md (cấu trúc file, mẫu test/story, quy ước SCSS/Tailwind, prop convention).
  2. Spec mỗi component: skill ds-spec đọc crawl JSON → Markdown gồm API table, danh sách demo cần cover, hành vi đặc biệt, dependency cho phép.
  3. Gọi codex: codex exec --skip-git-repo-check --dangerously-bypass-approvals-and-sandbox -C packages/ui "<RECIPE + SPEC + đường dẫn 5 mẫu>" — làm từng component hoặc nhóm 3–5 cái.
  4. Review: ds-review chấm; Claude sửa lệch API, lệch style, thiếu a11y; chạy vitest run <path> + build story.
  5. Chốt & ghi: cập nhật PROGRESS.md (bảng 84 dòng: spec / impl / test / story / review), commit theo nhóm.
Nguyên tắc. Không để codex quyết định token, cấu trúc export, hay dependency mới. Mọi thư viện thứ ba do Claude chốt trước trong spec. Codex chỉ điền phần thân theo khuôn.
