export const read = (v) =>
  typeof window === 'undefined'
    ? ''
    : getComputedStyle(document.documentElement).getPropertyValue(v).trim()

# Design Tokens

Source: `packages/tokens/src/styles/*.scss` → generated to CSS variables
(`@vn-dylan/tokens/css`), a Tailwind preset
(`@vn-dylan/tokens/tailwind-preset`) and TS constants (`@vn-dylan/tokens`).

Every variable is prefixed `--dyl-`. The Tailwind preset maps each one to a
semantic utility name. Swatches on this page read the **live value** — flip the
theme in the toolbar and reopen the page to see the dark overrides.

Runtime cascade order:

```
:root                        →  complete light palette
:root.dark                   →  dark-mode overrides (Tailwind `class` strategy)
[data-theme-schema="green"]   →  brand-hue overrides (see Theming & Modes)
```

## The opacity modifier

`primary` / `success` / `error` / `info` / `warning` / `content` / `gray` each
ship a `--dyl-*-channel` R G B triplet alongside the solid hex, so those
resolve through Tailwind's `rgb(var(...) / <alpha-value>)` pattern and support
`/NN` (`bg-primary/40`, `text-content/60`, …). `surface` / `border` / `bg` /
`overlay` stay solid-only — reach for `-subtle`, `overlay`, or `brightness-*`
there instead.

  <div style={{ display: 'flex', gap: '0.5rem', margin: '1rem 0' }}>
