# Consuming the system in another project

The four `@dylan-ds/*` packages publish to **GitHub Packages** (private, org
`dylan-ds`). Full copy of this guide, kept in sync: [`CONSUMING.md`](https://github.com/dylan-ds/Dylan.DesignSystem/blob/main/CONSUMING.md) in the repo root.

---

## 1. Authenticate

GitHub Packages needs auth even to read. In the **consuming** project's root
`.npmrc`:

<Markdown>{`
\`\`\`
@dylan-ds:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=\${GITHUB_TOKEN}
\`\`\`
`}</Markdown>

`GITHUB_TOKEN` = a classic Personal Access Token with the `read:packages` scope,
exported in the shell and set as an env var in CI. Never commit the token.

## 2. Install

<Markdown>{`
| Command | When |
| --- | --- |
| \`pnpm add @dylan-ds/ui\` | Always — pulls \`tokens\` / \`utils\` / \`icons\` automatically |
| \`pnpm add @dylan-ds/tokens\` | You extend \`tailwind.config\` with the preset |
| \`pnpm add @dylan-ds/utils\` | You call the hooks (\`useDarkMode\`, \`useThemeSchema\`, …) |
| \`pnpm add @dylan-ds/icons\` | You render icons directly |
`}</Markdown>

`react` and `react-dom` **v18** are peer dependencies — they must already be in
the project. The heavier libraries a few components use (`apexcharts`, `@tiptap/*`,
`@tanstack/react-table`, `jsvectormap`, `react-syntax-highlighter`,
`@floating-ui/react`) are normal dependencies of `@dylan-ds/ui` and install
automatically; tree-shaking keeps unused ones out of the bundle.

## 3. Stylesheet — imported once

```ts
// app entry, e.g. src/main.tsx
import '@dylan-ds/ui/styles.css'
```

One file: token custom properties (`:root` / `.dark` / schema overrides) +
Tailwind `base` / `components` / `utilities` + every component's semantic CSS.

## 4. Tailwind (optional)

Only if your app uses Tailwind and wants the token-aware utilities:

```ts
import { dylanPreset } from '@dylan-ds/tokens/tailwind-preset'
export default { presets: [dylanPreset], darkMode: 'class', content: [/* … */] }
```

## 5. Theming

`@dylan-ds/utils` ships headless hooks — call once near the app root, wire to your
own toggles:

```tsx
import { useDarkMode, useThemeSchema, useDirection } from '@dylan-ds/utils'

const [isDark, setMode] = useDarkMode()            // toggles `.dark` on <html>
useThemeSchema('green', isDark ? 'dark' : 'light') // brand schema vars
useDirection()                                     // persisted `dir`
```

Schema names: `themeSchemaNames` from `@dylan-ds/tokens` — `default`, `dark`,
`green`, `purple`, `orange`, `cyan`, `gold`, `pink`.

## 6. Upgrading

```bash
pnpm up '@dylan-ds/*' --latest
```

All four packages version in lockstep. See **Handbook → Contributing** for how a
new version is cut (Changesets → GitHub Actions).
